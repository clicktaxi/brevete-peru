## 0. Суть продукта

Бесплатное веб-приложение (PWA) для подготовки к теоретическому экзамену MTC (Перу) на водительскую лицензию.
Главное отличие от существующих испанских приложений (например, «Simulador MTC»): **целевой пользователь знает испанский
на уровне A1** — читает по слогам, знает несколько сотен слов, не понимает сложные конструкции
(«salvo que», «sin embargo», «ninguna de las alternativas»). Экзамен при этом только на испанском.

### Ключевой принцип: не учить испанский, а научить сдавать экзамен
Пользователь с A1 не выучит испанский за 2–4 недели подготовки. Он может:
1. **понять правило** — на родном языке (перевод + простое объяснение);
2. **узнать вопрос** на экзамене по картинке, номеру-«якорю» и 2–4 ключевым испанским словам;
3. **узнать верный ответ** по его ключевым словам-якорям, даже не понимая остальную фразу;
4. **не попасть в ловушку** — различать слова, которые переворачивают смысл (no, solo, salvo, prohibido/permitido, izquierda/derecha).

Весь функционал оценивается одним вопросом: «Поможет ли это человеку с A1 выбрать верную букву на испанском экзамене?»
Функции, которые учат «испанскому вообще», в MVP не делаем.

Все вопросы, ответы, переводы и объяснения — **в открытом доступе, без регистрации и без платных функций**.

### Параметры экзамена
| Параметр | Значение |
|---|---|
| Вопросов на экзамене | 40, случайно из балотарио категории |
| Порог сдачи | 35 правильных |
| Время | 40 минут |
| Банк A-I | 200 вопросов, варианты a–d, один верный |
| Язык экзамена | испанский |

### Языки
- Интерфейс: `ru`, `en`, `es`.
- Перевод вопросов: `ru`, `en` в MVP. Добавление языка = добавление файлов перевода, без правок кода.

## 1. Стек (не менять без согласования)

- **Next.js 15 (App Router) + TypeScript**, `output: 'export'` — полностью статический сайт, без сервера.
- **Tailwind CSS**, компоненты — свои, без тяжёлых UI-китов.
- **Данные:** JSON-файлы в репозитории (`/content`), бэкенда в MVP нет.
- **Прогресс пользователя:** IndexedDB через `idb-keyval` (с fallback в память, все обращения в try/catch).
- **PWA:** `serwist` (или ручной Service Worker) — офлайн после первого визита.
- **i18n:** маршруты с префиксом языка `/ru/...`, `/en/...`, `/es/...`; словари интерфейса в `/messages/{lang}.json`.
- **Парсинг PDF:** Python 3 (`pdfplumber`, `PyMuPDF`) — скрипты в `/scripts`, запускаются один раз.
- **Тесты:** Vitest (логика), Playwright (e2e основных сценариев).
- **Хостинг:** Cloudflare Pages (статический билд из `out/`).
- Пакетный менеджер: `pnpm`.

## 3. Данные

### 3.1 Схемы (TypeScript, положить в `/src/lib/types.ts` и валидировать через zod)

```ts
type Lang = 'es' | 'ru' | 'en';
type OptionKey = 'a' | 'b' | 'c' | 'd';

interface Category {
  id: 'a1' | 'a2a' | 'a2b' | 'a3a' | 'a3b' | 'a3c' | 'b2a' | 'b2b' | 'b2c';
  code: string;            // "A-I"
  examQuestions: 40;
  passScore: 35;
  timeLimitSec: 2400;
  sourcePdf: string;       // путь в /content/source
  sourceUrl: string;       // страница MTC на gob.pe
  sourceVersion: string;   // дата/хеш PDF
  title: Record<Lang, string>;
  description: Record<Lang, string>;
}

interface Question {
  id: string;              // "a1-038"
  category: Category['id'];
  number: number;          // номер в балотарио (1..200)
  topic: string;           // id из topics.json
  text: string;            // ИСПАНСКИЙ ОРИГИНАЛ, дословно
  options: Record<OptionKey, string>; // ИСПАНСКИЙ ОРИГИНАЛ
  correct: OptionKey;
  image?: string;          // "/images/a1/038.webp"
  sourcePage: number;      // страница PDF
  terms: string[];         // id терминов глоссария, встречающихся в вопросе
  anchors: QuestionAnchors;
  answerType: 'text' | 'combo' | 'none' | 'all'; // combo — «a y b son correctas», none — «Ninguna…», all — «Todas…»
  twins?: string[];        // id вопросов, которые легко спутать с этим (похожая формулировка, другой ответ)
}

interface QuestionTranslation {
  id: string;
  text: string;            // перевод вопроса
  options: Record<OptionKey, string>; // перевод вариантов
  gist: string;            // смысл вопроса в 3–7 словах простым языком: «Где можно высаживать пассажиров?»
  explanation: string;     // 2–4 КОРОТКИХ предложения простым языком: почему ответ верный
  trap?: string;           // чем неверные варианты похожи на верный и как их отличить
  legalRef?: string;       // статья Reglamento Nacional de Tránsito, если уместно
  // Пословный разбор (для «подстрочника»): каждая испанская фраза вопроса и вариантов
  // разбита на смысловые куски с переводом. Куски, склеенные обратно, дают исходный текст ДОСЛОВНО.
  gloss: {
    text: GlossChunk[];
    options: Record<OptionKey, GlossChunk[]>;
  };
  status: 'machine' | 'reviewed' | 'approved';
}

interface GlossChunk {
  es: string;              // "Recoger o dejar pasajeros"
  tr: string;              // "Сажать или высаживать пассажиров"
  kind?: 'logic' | 'anchor'; // logic — слово-переключатель смысла, anchor — якорь верного ответа
}

// Не зависит от языка перевода, хранится в questions.json рядом с вопросом
interface QuestionAnchors {
  questionKeys: string[];  // 2–4 испанских слова, по которым вопрос узнаётся: ["recoger", "pasajeros"]
  answerKeys: string[];    // 1–3 испанских слова/фразы, которые есть ТОЛЬКО в верном варианте: ["lugares autorizados"]
  // Правило проверки (validate): каждое answerKey встречается в верном варианте и НЕ встречается в неверных.
  // Если уникального якоря нет (варианты почти одинаковые) — answerKeys = [] и заполняется trap.
}

interface GlossaryTerm {
  id: string;              // "berma"
  es: string;
  tr: Partial<Record<Lang, string>>;
  note?: Partial<Record<Lang, string>>;
  example?: string;        // id вопроса-примера
  image?: string;
}
```

### 3.2 Правила контента (КРИТИЧНО)
1. Испанский текст вопросов и вариантов переносится из PDF **дословно**. Разрешено только чинить артефакты извлечения
   (переносы строк, разорванные слова, лигатуры `fi/fl`, кавычки вида `¿...¿` → `«...»` только если в PDF это явный дефект кодировки — логировать каждую такую правку в `scripts/fixes.log`).
2. Правильный ответ берётся **только из PDF**. Никогда не «исправлять» ответ по своему мнению. Если ответ кажется спорным — пометить в `content/a1/disputed.json` и сообщить мне.
3. Переводы и объяснения генерирует Claude Code, со статусом `machine`. Объяснение не должно противоречить ответу из PDF.
4. Картинки к вопросам (знаки, схемы) извлекаются из PDF по bounding box и сохраняются в webp. Если качество плохое — отметить в `content/a1/images-todo.json` (позже перерисуем в SVG).

### 3.3 Импорт (этап 1)
- Исходник: балотарио «Clase A, Categoría I» со страницы MTC
  https://www.gob.pe/institucion/mtc/informes-publicaciones/1928110-examen-de-conocimientos-para-postulantes-a-licencias-de-conducir
- Если скачать не получается (нет сети) — остановись и попроси меня положить PDF в `/content/source/A-I.pdf`.
- `scripts/import_pdf.py` → `content/a1/questions.json` + картинки.
- `scripts/validate.ts` проверяет:
  - ровно 200 вопросов, номера 1..200 без пропусков и дублей;
  - у каждого 4 непустых варианта и `correct ∈ {a,b,c,d}`;
  - все `image` существуют на диске;
  - все `terms` есть в глоссарии;
  - для каждого вопроса есть перевод `ru` и `en`;
  - склейка `gloss`-кусков даёт исходный ES-текст дословно (иначе подстрочник врёт);
  - каждый `answerKeys` есть в верном варианте и отсутствует в неверных;
  - `gist` ≤ 7 слов, каждое предложение `explanation` ≤ 15 слов;
  - повторный прогон импорта даёт идентичный JSON (детерминизм).
- Вывести отчёт: сколько вопросов с картинками, сколько правок в `fixes.log`, распределение по темам.

### 3.4 Темы
Классифицировать каждый вопрос в одну тему: `senales` (знаки), `semaforos` (светофоры), `marcas` (разметка),
`preferencia` (приоритет проезда), `velocidad` (скорость), `adelantamiento` (обгон), `estacionamiento` (стоянка),
`infracciones` (нарушения и штрафы), `documentos` (лицензия, SOAT, документы), `seguridad` (безопасность, алкоголь, ремни),
`peatones` (пешеходы), `primeros-auxilios`, `otros`. Классификацию делает Claude Code, я проверю выборочно.

### 3.5 Глоссарий
150+ терминов из вопросов A-I (calzada, berma, carril, adelantar, ceder el paso, intersección, bocina, luces direccionales,
papeleta, UIT, SOAT, crucero peatonal, vía férrea, rotonda, estacionar, voltear, giro en U…) + отдельный набор
**«экзаменационных формул»**: «Ninguna de las alternativas es correcta», «a y b son correctas», «Todas las anteriores»,
«Señale la afirmación correcta», «es correcto afirmar que», «De acuerdo al siguiente gráfico» — с переводом и пояснением ловушки.

## 4. Обучение для уровня испанского A1 (главная фича)

### 4.1 Путь пользователя по каждой теме (пошаговый, приложение ведёт само)
Тема проходится в 4 шага. Кнопка «Продолжить» на хабе всегда открывает следующий незавершённый шаг.

| Шаг | Что делает пользователь | Зачем при A1 | Переход дальше |
|---|---|---|---|
| 1. Слова темы | 10–20 карточек глоссария темы: ES-слово + перевод + картинка | Знать 15 слов темы — уже половина понимания вопроса | Все карточки просмотрены |
| 2. Понять | Вопросы темы на **родном языке** (вопрос и варианты переведены), ES мелко ниже | Понять правило, не спотыкаясь о язык | ≥80% верно |
| 3. Узнать | ES-вопрос + подстрочник; варианты на ES, якоря верных ответов подсвечены | Связать правило с испанскими словами | ≥80% верно |
| 4. Как на экзамене | Только ES, без подсказок; кнопка «Помощь» доступна, но ответ с помощью не засчитывается в «выучено» | Проверка, что узнаёт без перевода | ≥90% верно → тема «готова» |

Пороги считаются по последним 20 ответам в теме. Пользователь может перейти на любой шаг вручную.

### 4.2 Уровни помощи на карточке вопроса
Глобальная настройка (по умолчанию для нового пользователя с языком интерфейса ru/en — **уровень 1**) + переключатель на каждом вопросе:

| Уровень | Что видно |
|---|---|
| 1 — Родной язык | Вопрос и варианты крупно на родном языке, ES мелко под каждым |
| 2 — Подстрочник | ES крупно; под каждым смысловым куском (`gloss`) — перевод мелким шрифтом, как подписи |
| 3 — Подсказки | Только ES; тап по любому куску → поповер с переводом; кнопка «Перевести всё» |
| 4 — Экзамен | Только ES, никаких подсказок |

### 4.3 Подсветка «слов-переключателей» (защита от ловушек)
Отдельный словарь `content/glossary/logic.json` — слова, которые меняют смысл фразы на противоположный или ограничивают его:
`no, nunca, siempre, solo, solamente, únicamente, salvo, excepto, sin embargo, aun cuando, antes, después, prohibido, permitido,
obligatorio, debe, puede, izquierda, derecha, mayor, menor, más, menos, ninguna, todas, ambas, y, o`.
- На уровнях 1–3 такие слова в ES-тексте выделяются цветом (например, оранжевым жирным) с переводом в поповере.
- В объяснении ошибки, если неверный вариант отличается от верного одним таким словом, показывать это явно:
  «Вы выбрали *permitido* (разрешено), а верно *prohibido* (запрещено)».
- Мини-тренажёр «Слова-ловушки» (этап 2): 30 карточек ES → выбрать перевод из 4, до автоматизма.

### 4.4 Якоря ответа
- Для каждого вопроса хранится `anchors.answerKeys` — слова, которые есть только в верном варианте.
- На шаге 3 и в режиме изучения якоря подсвечиваются в верном варианте (зелёная подложка) с подписью
  «Запомните: верный ответ — где *lugares autorizados* (разрешённые места)».
- В разборе ошибок якорь показывается всегда.
- Для вопросов, где якоря нет (варианты различаются одним словом-переключателем) — показывается `trap`.

### 4.5 Вопросы-двойники
Вопросы из `twins` (похожие формулировки, разные ответы) — отдельный режим «Не перепутай»: показываются парами подряд,
после ответа — сравнение бок о бок с подсветкой отличающихся слов (diff по словам).

### 4.6 Вопросы с картинками
Картинка — самый надёжный якорь при A1. Отдельный фильтр «Вопросы с картинками» и режим «Узнай по картинке»:
показывается только картинка, пользователь выбирает ответ из 4 ES-вариантов. Знаки группируются по коду (R-6, R-3…).

### 4.7 Типовые формулы экзамена
Отдельный экран-памятка (из п. 3.5): формулы вопроса («Señale la afirmación correcta», «es correcto afirmar que»,
«De acuerdo al siguiente gráfico») и формулы вариантов («Ninguna de las alternativas es correcta», «a y b son correctas»,
«Todas las anteriores»). Для вопросов с `answerType` ≠ `text` — отдельная пометка на карточке: «Верный ответ — комбинация».

### 4.8 Интерфейс настоящего экзамена
Экран «Как выглядит экзамен» (этап 2): словарь кнопок и надписей реальной системы экзамена
(Siguiente, Anterior, Finalizar, Pregunta X de 40, Tiempo restante, Aprobado, Desaprobado) — чтобы на экзамене не растеряться.
Симулятор в режиме «как на экзамене» использует **те же испанские надписи** независимо от языка интерфейса.
Эталон — официальный симулятор MTC: https://sierdgtt.mtc.gob.pe/ . Сайт блокирует автоматический доступ,
поэтому не пытайся его парсить: я пришлю скриншоты экранов в `/docs/mtc-simulator/`. По ним повторить
порядок экранов, надписи и логику навигации максимально близко к оригиналу.
На странице `/how-to` и в результатах симулятора дать ссылку на официальный симулятор с подсказкой
«Когда проходите наш симулятор на 35+ три раза подряд — проверьте себя на официальном».

### 4.9 Озвучка
Кнопка 🔊 у вопроса и у каждого варианта, Web Speech API, голос `es-PE` → `es-419` → любой `es`, скорость 0.7× / 1×.
При A1 чтение и слух вместе помогают узнавать слова. Если голоса `es` в системе нет — кнопка скрыта.

### 4.10 Язык объяснений
Все переводы, `gist`, `explanation`, `trap` пишутся **простым языком**: короткие предложения, без канцелярита,
без юридических оборотов. Пример хорошего объяснения:
«Пассажиров можно сажать и высаживать только в разрешённых местах. Остальные варианты — нарушения.»

### 5.1 Карточка вопроса (общий компонент `QuestionCard`)
- Номер + текст ES, картинка (если есть, `max-height: 40vh`, тап — увеличение).
- 4 варианта с буквами a–d **в порядке балотарио** (перемешивание — опция в настройках, по умолчанию выкл).
- До ответа: варианты кликабельны. После: верный — зелёный, выбранный неверный — красный, остальные приглушены.
- Под ответом: объяснение на языке интерфейса, ссылки на термины, кнопки ★ «в избранное», «Сообщить об ошибке» (mailto с id вопроса), «Поделиться».
- В режимах `study`/`all` верный ответ показан сразу (как в балотарио).
- Крупная типографика: текст вопроса ≥18px, варианты ≥17px, тап-зоны ≥48px.

### 5.2 Симулятор
- 40 уникальных случайных вопросов категории (seed сохраняется в попытке).
- Таймер 40:00 сверху, при 0 — автозавершение.
- Навигация: следующий / предыдущий / сетка 1–40 с отметкой отвеченных; можно пропустить и вернуться.
- Ответ можно менять до завершения; правильность до завершения НЕ показывается.
- Защита от случайного выхода (confirm).
- Результат: «APROBADO / Сдано» при ≥35, иначе «DESAPROBADO / Не сдано», балл, время, разбор по темам, список ошибок с переходом к вопросам.
- Попытка сохраняется в IndexedDB; незавершённая попытка восстанавливается после перезагрузки.

### 5.3 Прогресс и готовность
Для каждого вопроса хранить: `seen`, `correctCount`, `wrongCount`, `streak`, `lastAnswer`, `starred`, `srs {ease, interval, due}`.
- Вопрос «выучен», если `streak ≥ 2`.
- В «ошибках» вопрос остаётся, пока `streak < 2` после последней ошибки.
- **Готовность** на хабе категории = доля симуляторов с 35+ среди последних 5 попыток + % выученных вопросов. Показать простой индикатор.
- Экспорт/импорт прогресса в JSON-файл (замена аккаунту в MVP).

### 5.4 Поиск
Клиентский полнотекстовый поиск (MiniSearch) по ES-тексту и по переводу на языке интерфейса, без учёта диакритики
(`señal` = `senal`). Поиск по номеру вопроса.

## 6. SEO и открытый доступ
- Все страницы вопросов, тем и глоссария генерируются статически (SSG) на всех языках.
- `hreflang` между языковыми версиями, canonical, `sitemap.xml`, `robots.txt`.
- JSON-LD `Quiz` на странице вопроса, `FAQPage` на страницах тем.
- Open Graph: для каждой страницы вопроса — генерировать OG-картинку на этапе билда (текст вопроса ES + номер).
- Прогресс/кнопки работают как island поверх статического HTML: страница вопроса читаема без JS.
- Выгрузка `/api/a1.json` (статический файл) — весь банк с переводами, для открытого использования.

## 7. Нефункциональные требования
- Mobile-first, от 360px; тёмная тема (по системной + переключатель).
- Lighthouse mobile на странице вопроса: Performance ≥90, Accessibility ≥90, SEO ≥95.
- Страница вопроса ≤150 KB (без картинки), JS на странице тренировки ≤120 KB gzip.
- Офлайн: после первого открытия категории вся категория (JSON + картинки) кешируется.
- Аналитика: Plausible (скрипт подключается только если задан `NEXT_PUBLIC_PLAUSIBLE_DOMAIN`). События: `exam_start`, `exam_finish {score}`, `level_change`.
- Никаких cookie-баннеров, трекеров, рекламы, пейволлов.
- Дисклеймер в футере на всех языках: «Неофициальный учебный ресурс. Вопросы — балотарио MTC (ссылка)».

## 8. Дизайн
- Светлый, спокойный, «учебный»: фон `#F7FAFB`, акцент — бирюзовый/тил, верный — зелёный, ошибка — красный; контраст AA.
- Шрифт: Inter (или system-ui), цифры таймера — tabular.
- Никаких стоковых фото машин на главной — простые иконки/иллюстрации категорий (SVG).
- Нижняя навигация на мобильном: Учиться · Тренировка · Экзамен · Ещё.
